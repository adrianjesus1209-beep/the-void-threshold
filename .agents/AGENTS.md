# Reglas del Proyecto

- Todos los mensajes de commit en Git deben redactarse siempre en español de forma clara y concisa.
- El archivo `database/base_datos_threshold.sql` es un dump de referencia y NO debe ser modificado directamente por el agente. Cualquier cambio en la base de datos debe realizarse mediante scripts SQL o consultas directas al servidor MySQL, no editando ese archivo.
