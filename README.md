# THE VOID THRESHOLD

Landing page interactiva para un juego indie de terror pixel art con panel de administración.

## Tecnologías

- **Backend:** PHP (vanilla) + MySQL (MariaDB)
- **Frontend:** HTML, Tailwind CSS, JavaScript vanilla
- **Extras:** GSAP ScrollTrigger, Chart.js, jsPDF

## Instalación

1. Clonar: `git clone https://github.com/adrianjesus1209-beep/the-void-threshold_JUEGO.git`
2. Mover a tu directorio dehtdocs
3. Configurar `api/config_db.php` con tus credenciales MySQL
4. Importar la base de datos desde `database/`
5. Generar token y contraseña hash, insertarlos en la BD
6. Acceder a la landing y al panel de admin
